# Notebooks — Redirección

Todos los notebooks se centralizaron en `notebooks/` en la raíz del proyecto.

- `notebooks/AetherControl_Notebook.ipynb` — App Android Kotlin (MVVM, Compose)
- `notebooks/EMA_Estadistica.ipynb` — Filtro EMA y estadística TS4D3

Abre desde la raíz:
```bash
jupyter notebook notebooks/AetherControl_Notebook.ipynb
jupyter notebook notebooks/EMA_Estadistica.ipynb
```
