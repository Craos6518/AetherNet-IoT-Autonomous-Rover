Nota de adaptación trazable: El PDF del programa describe .NET/C#/Xamarin/XAML. El proyecto implementa los mismos conceptos y patrones con Kotlin/Compose (estándar Android 2024-2025, 100% FOSS RNF-3.1). Equivalencia mapeada en docs/materias/programacion-movil.md:7.

Alineación con el syllabus TS6C3 (U1–U4)

  • U1 Plataforma y Lenguaje (.NET → Kotlin): Android Studio + Gradle; Kotlin con null-safety, data classes y sealed interfaces (DashboardUiState), Coroutines/Flow.
  • U2 Front Móvil (XAML → Compose): UI declarativa Compose — Column/Row/LazyColumn ≈ StackLayout/Grid, theming Material3, recomposición por estado.
  • U3 Back Móvil (MVVM + Emuladores): MVVM nativo — View (Compose) observa uiState: StateFlow expuesto por DashboardViewModel + Repository + viewModelScope; AVD + SM-X620.
  • U4 Datos y Entorno (REST/JSON, HW, Permisos): Canal principal MQTT/WebSocket pub/sub (RF-1.1, JSON), Retrofit para REST puntual; Room local; Bluetooth SPP (RFCOMM) como contingencia Wi-Fi (RF-1.3, BLUETOOTH_CONNECT Android 12+).
