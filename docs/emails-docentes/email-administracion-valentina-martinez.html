Alineación con el syllabus TS683

  • U1 (Metodologías y Planificación — Scrum, PSP/TSP, BDD): Product Backlog MoSCoW por 5 áreas, ventana 8 semanas / 4 Sprints con dependencias y grafo habilitador, 4 Historias BDD (Dado/Cuando/Entonces) como fuente de verdad para tests.
  • U2 (Riesgos, Configuración, Medición y Análisis): Matriz formal de riesgos con mitigación y dueño, gestión de configuración vía Git + GitHub Actions + arduino-cli (quality gate), KPIs de producto definidos antes de construir.
  • U3 (Calidad, Costos, Monitoreo y Control): Plan SQA y criterios BDD, pipeline CI con 6 jobs como puerta de calidad, inventario hardware como base de costos y restricción FOSS 100%, mecanismo de seguimiento (PM-05), retros (PM-06) y Planning Poker (PM-07).
