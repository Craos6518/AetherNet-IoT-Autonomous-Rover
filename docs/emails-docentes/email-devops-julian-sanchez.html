Alineación con el syllabus TS6D3 (T1–T6)

  • T1 CALMS: Ciclo Plan→Code→Build→Test→Deploy→Operate→Monitor por sprints; Lean con base fundacional Sprint 1; Sharing vía trazabilidad HU↔RF↔sprint↔archivo.
  • T2 Git: Repo único, ramas main/develop, feature branches + PRs; commits trazables a IDs del backlog.
  • T3 Linux/Shell: Linux Mint + Docker CLI, scripts shell en pipeline (curl arduino-cli, setup cores/librerías), gestión de puertos serie.
  • T4 Docker Compose (Taller 1): 3 servicios (FastAPI + PostgreSQL 16 + Mosquitto 2.0) en aethernet-net, healthcheck pg_isready + depends_on: service_healthy, env.example.
  • T5 CI/CD (Taller 2): .github/workflows/ci.yml — 6 jobs: backend-test, firmware-compile (matriz arduino-cli), docker-build, stats-test, security-scan (Trivy); android-build en plantilla desactivada.
  • T6 Monitoreo: Logs contenedores/Mosquitto montados; KPIs PRD conceptuales; Prometheus/Grafana como brecha post-Sprint 4 — alerta de negocio (Telegram + LED) vía RF-4.1/HU-02 sí implementada.
