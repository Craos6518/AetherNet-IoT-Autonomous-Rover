Aplicación núcleo 1 de 3 · Unidad 1 · Estadística descriptiva

Filtro EMA: leer el mundo sin “brincos”

El sensor ultrasónico “brinca” por ruido eléctrico y ecos fantasma. Con un filtro exponencial suavizo la señal en tiempo real:

St=α · Yt+(1 − α) · St−1

Yt lectura actual  ·  St valor suavizado  ·  α = factor de suavizado (0 a 1)

Parámetro elegido: α = 0.2 🎯 Meta del proyecto (KPI): reducción de desviación estándar ≥ 85 % Validación numérica en Python
🧪 Demostración interactiva — la misma idea que valido en Python (stats/ema_filter.py)
Reducción de ruido: — Retraso de respuesta: —
lectura cruda HC-SR04 señal filtrada EMA distancia real

⚠️ Compromiso clave: bajar α suaviza más pero aumenta el retraso — un robot que frena tarde también choca. Por eso α se valida con datos, no “a ojo”. Prueba los valores rápidos y observa ambas métricas.

Nota internaLas fórmulas se dicen con naturalidad, no se leen. Si interrumpe con preguntas técnicas, es buena señal: hay todo el bloque de diálogo para eso.
